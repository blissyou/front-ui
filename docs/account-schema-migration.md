# 이메일 계정 모델 정리

계정 엔티티는 id, email, password_hash, role, created_at만 사용합니다.
회원 전체를 매번 수정하던 시작 시 정리 코드는 제거했습니다.

현재 기본 설정은 프로세스 종료 시 사라지는 H2 메모리 DB입니다.
서버 재시작 시 새 스키마로 생성됩니다.

별도 영속 DB를 사용하는 배포에서는 배포 전에 스키마 마이그레이션이 필요합니다.
Hibernate `ddl-auto=update`는 제거된 필드의 기존 컬럼을 자동 삭제하지 않습니다.
기존 login_id, name, phone, school, grade의 NOT NULL 제약이 남아 있으면 신규 가입이 실패합니다.
데이터 보존 정책을 확인한 후 해당 컬럼과 관련 제약을 DB 마이그레이션으로 제거하세요.
이 변경 작업에서는 외부 DB나 기존 저장 데이터를 직접 삭제하지 않았습니다.
